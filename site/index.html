Before trusting 99.9% accuracy, read this

This public dataset is synthetic. Its churn labels were generated from hard cut-offs, and five plain rules with no machine learning already get accuracy. Every customer the rules flag churned. So the useful question is not “is the model accurate?” but “what does ML add over the rules?” Here, it catches the remaining churners that depend on combinations of features, which cuts errors from to .

On real customer data, expect AUC in the 0.75–0.90 range. The planner and explanations work the same way.

How it works

  1. Train: Python compares a rule baseline, Logistic Regression, Random Forest, XGBoost and LightGBM on 440k customers.
  2. Export: the LightGBM trees are written to a 300 KB JSON file.
  3. Score in the browser: JavaScript runs the trees and computes exact TreeSHAP, tested to match Python to 1e-6.
  4. Decide: expected value = churn risk × offer success × customer value − cost, under your budget.
